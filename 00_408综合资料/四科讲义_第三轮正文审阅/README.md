## 下载并还原完整包

原 ZIP 为 **188,790,242 字节**，超过 GitHub 普通文件的 100 MiB 上限，因此按原始字节顺序无损拆成三份。分卷未重新压缩，合并后与本次本地交付的完整 ZIP 逐字节相同；不依赖 Git LFS。

下载下列五个文件并放在同一目录。浏览器打开文件后，选择 **Download raw file** 保存原始文件，避免保存网页。

- [第 1 卷：64 MiB](408讲义_第三轮正文审阅稿与源码.zip.001)
- [第 2 卷：64 MiB](408讲义_第三轮正文审阅稿与源码.zip.002)

- [分卷清单与 SHA-256](archive_parts.json)
- [校验与还原脚本](restore_archive.py)

安装 Python 3，在这个目录运行：

```bash
python restore_archive.py
```

脚本逐卷检查大小和 SHA-256，再校验合并 ZIP 的 SHA-256 以及全部 1,568 个文件的 CRC，成功后生成 `408讲义_第三轮正文审阅稿与源码.zip`。已存在且正确的完整包会直接保留；其他同名文件不会被覆盖。也可通过 `--output` 指定其他输出路径。

## 包内编辑与构建入口

解压后进入 `408_lecture_notes/`：

- `README.md`、`CONTENT_REVIEW.md`：使用说明与当前审阅入口。
- `manuscript/`：分章 Markdown 与四科合并稿。
- `figures/`、`tools/draw_*_figures.py`：可编辑图稿、共享数据与绘图源。
- `tools/book_preamble.tex`、`tools/book_images.lua`：排版样式与转换规则。
- `build/revision3/`：本轮 LaTeX 中间源码。
- `editorial/`：覆盖表、选题与错题去向、题源、复算、独立内容审校及未解决问题。

按依赖说明配置 Python、Pandoc、XeLaTeX、Inkscape 与中文字体后，用 `bash build_review.sh` 导出四科正文审阅 PDF。该命令不运行讲义分页、裁切或逐页视觉检查。
