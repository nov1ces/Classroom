# CN05 王道课件续编与核对记录

主母本为项目【课件】计算机网络基础考点讲解中的王道课件。本章登记10份、145个文件页，具体主题到正文锚点见course_coverage.json。

前一编写阶段已实质扩写正文和重绘本章CN_course图；恢复阶段核对现有正文、逐文件文本的知识组及关键结论，建立真实主题映射，补充数值复算。课程宣传与重复动画布局合并处理。逐页索引范围不等于每页原图均经独立视觉审阅，图像承载内容按关键机制和数值组核对；新增图已全尺寸查看，最终PDF另行逐页审阅。

数值检查见numeric_verification.json及CN01/code/verify_cn_models.py；首批独立检查另见全局sources/reviews/independent。原生公式、表格、时序和地址运算分别核对符号、单位与前提。

校正保留：CRC仅未检出错误、保证条件依生成多项式；CTS/ACK单地址为接收地址；IPv4首部校验全0不表示关闭；快重传先有原ACK再计三重复ACK；历史源点抑制保留协议年代。

代码部分按本章协议模型描述，未引入与教材数据结构约定冲突的实现。严蔚敏教材未作为本章协议来源。当前最终PDF视觉状态见visual_review.json。
