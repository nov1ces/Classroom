{\color{ink}\bfseries 例 4-2}\par\vspace{1bp}在\(i=\allowbreak{}4\)的字符 c 处，普通 next 使 j 按4\(\to \)3\(\to \)2\(\to \)1\(\to \)0回退，连续失败4次；nextval 使 j 从4直接到0，只失败1次。前三个 a 比较3次，随后从\(i=\allowbreak{}5\)匹配 aaaab 比较5次，故普通 next 共\(3+\allowbreak{}4+\allowbreak{}5=\allowbreak{}12\)次，nextval 共\(3+\allowbreak{}1+\allowbreak{}5=\allowbreak{}9\)次，首次成功位置均为5；\(j=\allowbreak{}0\)分支不计字符比较。
