# 数据结构全稿编辑记录

本目录记录实际完成的8章正文、60个暂定知识组、47道源题（44道主例和3道来源题自测）、97条已读错题的逐条去向、21幅教学图与66项计算/过程核验。题目身份统计只针对选入题，不表示全题库统计或考试频率。

第二轮仅做内容修订，范围和实际核读页见 `editorial/revision2/DS_revision.md`、`DS_revision_sources.json`。新增LR/RL状态图、5阶B树分裂/借并传播与排序独立比较列；原真题及典型题条件保留。V1讲义PDF未覆盖，本轮没有进行讲义PDF分页或视觉/排版检查；V1通过报告仅作为历史记录。

正文在 `manuscript/DS/`。读者题源只写【年份】或〖原节号-原题号〗，个人原作答仅保留在内部记录。`chapter_records.json` 为主要台账，`selected_questions.csv`、`errors_destinations.csv` 便于筛选；`content_lock.json` 保存锁稿时各章SHA。

题干精确位置优先使用实际已读取的用户题页PDF或完整社区复原卷，主书答案页另列。未逐项确认的主书题干页不填写推测值。社区复原卷并非官方原卷或官方答案发布；所选真题通过题文、年份、题号、图示和解答互证，不冒充官方认证。

`sources/DS_7.3_comprehensive_003.png` 关闭了RV-024：原书PDF307、印刷295确为§7.3综合应用题03，原题本就要求依次插入34、23、15、98、115、28、107并逐步保持AVL。它不是同节同号选择题，也没有把选择设问改成构树。

从解压项目根目录可独立复算、重绘：

```bash
python tools/draw_ds_figures.py
python editorial/full/DS/verification.py
```

绘图需要Inkscape与Noto Sans CJK SC字体；计算脚本只用Python标准库，读取已交付图数据，不需要原始大书或外网。`build_records.py` 是本次内部资料汇编脚本，包含原工作区的来源索引位置，不是日常PDF构建依赖；交付后的正式台账以已保存JSON/CSV为准。

`results.json` 保存实际数值和过程，含KMP与朴素查找穷举互证、含重复值的快排检查、AVL逐次平衡、Dijkstra与路径枚举互证、唯一拓扑与排列枚举互证、AOE四个选项改时长重算、置换选择全部19条记录的工作区事件，以及第二轮实际图稿每个状态的BST/B树约束与旋转、分裂、借并传播。66条记录不是文件存在性检查，也不能代替源题核验。

97条错题均有明确正文或复习去向。部分原题采用重复合并或只保留原图作复习，不等于97道原题全部在本轮再次完整独立解答；没有原作答推理时不判断个人当时的思维错误。原题条件缺陷、正式2027大纲细目未取得等限制列在台账 `unresolved`。

第二轮正文与机制复核完成，当前供内容审阅。`historical_v1_pdf_review` 保留旧成稿报告，`final_pdf_review` 明确本轮未执行；本目录的机制图检查与计算不冒充讲义PDF检查。
