# 四科统一约定与独立审校重点

日期：2026-10-16。内部审校材料；本文件不进入学习正文。它约束术语和假设，并不替代章节的知识核验。

## 本轮采用的呈现标准

正文题源只用真题年份 `【2018】` 或非真题位置 `〖2.3-054〗`。经修改的真题必须显式写“改编”，原创必须显式写“原创”；不能用年份短标签掩盖题意改动。完整年份、题号、书页、图示核验、个人错题身份和作答只保留内部台账。正文不写原作答，不写“做题本”，也不显示 ERR 编号。

定义、机制、成立条件与连续推导按已确认样章的深度保留。不把一般机制换成只有名词的对照表；也不在每个微小概念上重复完整模板。不能把文件可访问、ID 出现、程序运行或 PDF 可搜索分别当作已精读、知识讲足、结论正确或视觉通过。

## 地址、容量与存储层次

1. 使用二进制容量时优先明确 KiB、MiB，题干原用 KB 时保留原题并就近说明本题按 $2^{10}$ B 解释；网络速率 kbit/s、Mbit/s 默认为十进制。字长、字节和地址单元分别说明。一个存储字不固定等于一个字节。
2. 地址字段从低位开始：块内或页内偏移在最低位；若按字节编址，大小为 $2^k$ B 才对应 k 位偏移。若按字编址，不能再无条件加减字节位数。
3. 虚页号经页表映射到物理页框号，页内偏移不变；TLB 缓存的是近期地址转换信息。Cache 缓存数据或指令块。TLB 未命中不等于缺页，Cache 未命中也不等于缺页。
4. 页/页框用于虚拟存储，块/Cache 行用于高速缓存，文件块/磁盘块需按上下文定义。计组讲硬件转换路径，OS 讲映射维护、分配、缺页处理，二者不冲突：OS 维护规则，MMU 执行常规运行时地址转换。
5. 多级页表空间要说明是否只分配已用下级页表。有效访问时间说明 TLB/Cache 是串行还是并行、缺页率是否包含保护异常、缺页服务时间是否包含重启访存。不能套一个不带时间路径的统一公式。
6. Cache 命中率计算说明初态、映射规则、替换策略、访问是字还是块、是否跨块以及写分配策略。特殊分组题保留它的分组表，不能替成通常的块号模组数。

## 运行、同步与中断

1. 并发不要求同时执行；运行占有 CPU，就绪有执行条件而等 CPU，阻塞等事件且暂不可调度。唤醒只保证转为就绪。模式切换不必更换进程，上下文切换通常涉及执行主体变化。
2. 同步约束先后，互斥约束同一资源上的访问重叠。记录型信号量 P 先减后判断，负数表示等待；被 V 唤醒的本次 P 不再重复减。除明确队列规则，不从信号量存在推出 FIFO 或无饥饿。
3. 原子操作需说明作用范围及存储顺序假设。关本核中断不能阻止其他核访问；普通读写伪代码中的 Peterson 模型默认顺序一致性，不能直接当现代 C/C++ 并发代码。
4. 条件变量等待会释放关联互斥锁，返回前重新取得；条件判断在共享状态上。信号量 V 可保存许可，条件变量 signal 无等待者时不保存通知。Hoare 与 Mesa/POSIX 唤醒规则分别标条件。
5. 中断/异常的分类采用所讲体系结构和教材语境，不把所有 trap 当外中断，也不把异常一律当错误。CPU 响应硬件中断和中断服务软件保存现场是不同阶段。
6. 查询 I/O 由 CPU 反复检查并搬运；中断 I/O 使等待期间可运行别的工作，但逐次数据传送通常仍由 CPU 完成；DMA 在控制器组织下于设备与主存间直接传送，CPU 仍需设置并处理完成。不能写 DMA 全程不占总线或 CPU 完全不参与。

## 程序、文件与数据结构

1. 编译/汇编产生目标文件，链接组合目标与库并处理符号/重定位，装入建立运行时地址映像。静态/动态修饰的是何时完成相应链接或重定位，不能把动态装入与动态链接同义化。
2. 代码段、只读数据、已初始化数据、BSS、堆和栈按通行模型区分；不能把已初始化全局变量写成指令代码。返回地址的位置依 ISA 与调用约定，不一律写主存栈。
3. 文件打开表、目录项与 inode 各自说明作用。硬链接增加同一文件 inode 的目录项引用；软链接保存目标路径，不能把两种引用计数混用。打开文件仍有引用时的删除行为按所采用系统语义说明。
4. 下标和指针先定义；循环区间采用闭区间或半开区间时保持一致。空树、空表、单元素、最后一次循环等边界展示决定性一步。复杂度明确输入规模、基本操作和平均分布假设。
5. 树/图公式保留连通、无环、有向/无向、简单图等条件。拓扑序不等于任何有向图的顶点编号。排序稳定性指相等关键字记录的原相对次序，并区分某次运行保持与算法保证稳定。

## 网络时间、编号与协议

1. 发送时延是 L/R，传播时延是 d/v；逐跳存储转发从完整接收后再发送开始。传播时延与分组长度无关，发送时延与距离无关。报文/分组交换先标链路数与中间设备数。
2. MAC 地址逐跳变，IP 地址在无 NAT 等转换时保持源/目的端点，TTL 每经路由转发减一。ARP 解析本链路下一跳，不是直接解析任意远端目的主机。
3. GBN 的确认序号约定（最后收到还是下一期望）须明示；SR 接收缓存和接收窗口独立说明。TCP 按字节编号，确认号是下一个期望字节，SYN 与 FIN 各占一个序号，纯 ACK 不占。
4. 流量控制保护接收端，拥塞控制约束网络负荷。发送可用窗口除 min(rwnd,cwnd) 外还要扣除在途未确认数据。慢开始/拥塞避免按何版本、按轮还是逐 ACK 更新说明，不能把所有 TCP 实现等同于一个考试模型。
5. 子网可用主机数 $2^h-2$ 限定普通 IPv4 单播子网；/31 点对点、/32 主机路由单列边界。IP 分片偏移单位 8 B，非末片载荷需为 8 B 整数倍。IPv6 路由器不代源端分片。
6. 路由算法给状态、消息与更新先后；距离向量不是全网立即同步最短路。DNS 缓存和递归/迭代区分，HTTP 时延说明连接是否已建、持久/非持久、并行/流水、DNS/对象长度是否忽略。
