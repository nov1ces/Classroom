## 构建与编辑

正文编辑入口为 `manuscript/OS/03_同步互斥与信号量.md`；排版样式为 `tools/sample.tex`；图稿源为 `tools/draw_figures.py` 与 `figures/*.svg`。SVG、PNG及用于PDF的矢量图共用同一图稿代码；有计算数据的图读取 `figures/model_data.json`。

在本目录运行：

```bash
python -m pip install -r requirements.txt
./build.sh
```

构建会合并编辑台账，核验教学过程，生成SVG/PNG/矢量PDF，使用Pandoc与XeLaTeX排版，随后输出结构审计和全部页面图。视觉检查需要实际查看渲染图，脚本不会把文件存在当作视觉通过。

已实测：Python 3.12、PyMuPDF 1.26.6、Pillow 12.3.0、Pandoc 3.1.11.1、Inkscape 1.4、TeX Live 2025/dev，系统字体Noto Serif CJK SC、Noto Sans CJK SC与Noto Sans Mono CJK SC。排版需要常规LaTeX包 `fontspec`、`fancyhdr`、`titlesec`、`fvextra`、`longtable`、`hyperref`、`bookmark` 等。Debian/Ubuntu可由 `texlive-xetex texlive-latex-extra fonts-noto-cjk fontconfig pandoc inkscape` 提供主要系统依赖。

生成的 `build/os_sync_body.tex` 可直接编辑；持久修改应写回Markdown或模板，避免下次构建被覆盖。PDF正文、表格、公式和代码均以排版对象输出；插图由SVG导出矢量，不整页图片化。

覆盖表以 `editorial/scope/base_coverage.json` 保留原始规划，以 `tools/sync_editorial.py` 回填样章和错题关联。`editorial/scope/build_scope.py` 保留最初图读条目与目录生成依据，不在常规样章构建中运行。若重新生成整个范围初稿，应先保存和核对原有覆盖ID及样章回填，不能用新的行序重新编号。

PDF重建不需要复制800MB原书；源题再核验则需保留台账所指原始材料路径。本包不重复分发四本原书和全部课件，保留本轮实际使用的定位、题页证据及文件指纹。
