## 考试大纲的年度与发布主体

最终目标年度暂按2027建立。教育部教育考试院编制的2027大纲已有高等教育出版社出版记录。直接可读的[出版社详情页](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=6aa97a0be119ac9729dd09ea)确认书名、作者、2026年9月、ISBN 978-7-04-068451-3及96页；详情与目录为空，没有正式考试内容全文。

[出版社门户页](https://www.hep.com.cn/book/show/2099763850751057921)直接访问返回需JavaScript，搜索摘要给出更细日期，本轮仅采用可直接读到的月份。[中国教育考试网研考大纲栏目](https://yankao.neea.edu.cn/html1/category/1509/6235-1.htm)未在本轮提供2027可读全文。不能写“2027尚未发布”，也不能把出版书目当成正式细目已读。

当前以本地11页转录副本作为暂定细目边界，全部266条有规划去向，但**2027官方逐条覆盖仍待核验**。不依据第三方“无变化”传闻宣布差异为零。正式全文是范围定稿的真实缺项，不是错题材料没有提供。

## 样章题源与一手机制资料

五道入选真题为2009-45、2014-47、2018-28、2022-46、2024-46。完整题干、选项（选择题）、必要图、年份题号、参考答案均已通过王道扫描页和相应年份的[社区重建卷仓库](https://github.com/neville-studio/408-exam-paper)交叉核对。下载URL、文件指纹与对应题页截图在 `os_exam_checks/` 及错题图证目录；2025-45已核但留作备用。社区重建卷为二手重建，不称官方原始发布；王道答案加独立求解也不冒称已取得官方答案。

条件等待机制补核了[Oracle官方文档 Using Condition Variables](https://docs.oracle.com/cd/E37838_01/html/E61057/sync-21067.html)的等待、通知、丢失唤醒、例18—20有限缓冲过程。该页于本轮可直接读取，支持“等待释放锁、返回重取锁、通知不积累、while重检”及其典型模型。正文示例将变量统一为count/notEmpty/notFull，省略C接口细节和索引实现，等待与通知语义保留。

The Open Group Issue 8[条件等待](https://pubs.opengroup.org/onlinepubs/9799919799/functions/pthread_cond_clockwait.html)与[条件通知](https://pubs.opengroup.org/onlinepubs/9799919799/functions/pthread_cond_broadcast.html)在搜索索引中可读到规范片段；直接页面访问为403，本轮不声称读完规范全文。关键机制同时用可访问的Oracle一手接口文档与原书核对。Mesa式与Hoare式的不同在正文明确分开，不以任一接口实现代表全部管程定义。

## 冲突怎样处理

| 问题 | 本轮处理 |
| --- | --- |
| 课件把原语一概说成关中断实现 | 正文限定本CPU、单处理机与相关执行条件；多处理机不能靠本CPU关中断互斥。 |
| 读写入口量有时被称“写优先” | 正文说明取得gate后阻止新读者进入；FIFO和进度等前提另列，不声称绝对写优先或天然无饥饿。 |
| 经典缓冲把full直接称“产品数” | 加入许可预留的具体状态，负值仍按等待队列解释。 |
| 2014题书中说明与代码互斥量名称不一致 | 题干保持原意；采用统一mutex+batch四量解法，并复算。不是修改真题条件。 |
| 2009题没有明写初始为空 | 原题不添条件，解答显式声明采用参考答案的空初态，并给a奇b偶的一般初值。 |
| 原做题本误排或编辑替换 | 四处已从原书恢复，保留原样、恢复文本及原书页；未把修复后的文本冒充做题本原文。 |

其他具体条件问题见[未解决问题](../未解决问题与后续任务.md)。本轮没有建立全题库年份统计，不使用“高频”“近年趋势”或虚构百分比。目录深度与选题理由是教学判断。

## 真实缺项及对本轮的影响

正式2027全文仍需取得，以便范围定稿。其他28章仍须阅读主资料和逐题比较合适真题；已附错题已经继续处理，没有因整理状态被跳过。个别题源条件不足、原作答与书答一致的记录已单列，暂不将其当成确认的个人错误证据。样章所需条件已核明，本轮没有需要用户重新提交或统一格式化的错题材料。
