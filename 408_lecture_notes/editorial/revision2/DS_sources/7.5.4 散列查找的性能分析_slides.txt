回顾开放定址法的几种常用“探测序列”
di = 0, 1, 2, 3, …, m-1
di = 02, 12, -12, 22, -22, …, k2, -k2。其中k≤m/2
di 是一个伪随机序列，如 di= 0, 5, 3, 11, …
di = i×hash2(key)。其中 hash2(key) 是另一散列函数
开放定址法：Hi = (H(key) + di) % m ，其中，Hi 表示第 i 次发生冲突时的散列地址；i = 0, 
1, 2,…, k（k≤m - 1），m表示散列表表长；di为增量序列；

使用“平方探测法”减少聚集现象
平方探测法（又称二次探测法）：di = 02, 12, -12, 22, -22, …, k2, -k2，其中k≤m/2
d0 = 0，d1 = 1，d2 = -1，d3 = 4，d4 = -4，d5 = 9，d6 = -9….
散列地址 #8，将被初始散列地址为7、8 的元素争
夺。显然，“聚集”现象没有线性探测法那么严重。
结论：采用线性探测法处理冲突更容易导致“聚集（堆积）现象”，用其他方法处理冲突可以将元
素“打散”，从而减少“聚集（堆积）现象”
