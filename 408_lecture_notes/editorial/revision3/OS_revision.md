## 共同维度比较

- 第1章补宏内核／微内核的服务位置、通信边界、故障影响、扩展和性能代价。
- 第2章补进程／线程的资源与现场归属，以及 ULT／KLT 的管理、调度、切换和内核可见性；保留映射模型和第二轮调度比较。
- 第4章补预防／避免／检测的决定时机、依据、风险处理、保证和代价，区分未来最大 Need 与当前未满足 Request。
- 第5章补基本分页／请求分页的驻留要求、映射字段、未命中分支、调页与原指令重试，不重复第二轮页／段／段页式表。
- 第6章补目录项、磁盘 inode、内存 inode、打开实例／描述符的定位链与生命周期，不重复第二轮分配方式表。
- 第7章补 FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK 的选择和服务方向、端点／折返点、回跳是否服务及等待边界。SSTF 只在持续近处请求等条件下有饥饿风险，扫描也不无条件具有固定等待上界。

比较依据承接选页与保存转录重新核读。本接续作者实际读取了 `OS_sources/slide_read_selections.json` 所列 11 份选页转录；不把转录阅读称为整套课件逐页图读，也不声称通读主书。课件的 SCAN／LOOK 同名约定、部分平均值误算、读写文字笔误等没有直接沿用。详细边界见源清单的 `source_conditions_not_copied_blindly`。

## 图稿与复算

2022 目录题的树形层次和五行名字／inode／磁盘块表以 SVG 重画，并导出 PNG。`OS_file_directory_2022.svg` 与 PNG 由 `editorial/full/OS/model_data.json` 的 `directory_2022` 数据生成，已实际打开 PNG 核对四条目录包含边与全部五行数据。其余新增题用可编辑的 Markdown 表或公式保留必要数据。单图生成命令为：

```bash
python tools/draw_os_figures.py --revision3-only
```

本轮仅调用该增量命令，没有重新生成旧图。计算脚本只依赖交付的本地模型数据与 Python 标准库，不要求原书绝对路径存在：

```bash
python editorial/full/OS/verification.py
```

实际结果为 **66 项 PASS：原 37 项结果逐项保留，新增 29 项**。新增计算包括缺页状态轨迹、两级表项地址、文件容量与索引路径、720 种六操作排列的状态前提筛选，以及 SSTF 逐段距离和 CHS 正反算。结果在 `editorial/full/OS/results.json` 与 `editorial/revision3/OS_results.json`，过程在 `editorial/full/OS/process_traces.json`。
