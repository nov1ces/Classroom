## 错题数据结构说明

```json
[
  {
    "章号": "第1章",
    "章名": "绪论",
    "节列表": [
      {
        "节号": "1.1",
        "节名": "数据结构的基本概念",
        "错题列表": [
          {
            "题号": 5,
            "错选": "B",
            "PDF页码": 5
          }
        ]
      }
    ]
  }
]
```

- **错题规模汇总**：
  - 数据结构：8 章共 **97** 道错题
  - 计算机组成原理：7 章共 **130** 道错题
  - 操作系统：5 章共 **133** 道错题
  - 计算机网络：6 章共 **97** 道错题
  - **总计**：**457** 道错题
